# Project Development & Evaluation Priorities

Build, refine, and evaluate this project strictly around the following five evaluation parameters from the Hack2Skill AI Evaluation rubric. Prioritize these criteria throughout development, architecture, implementation, testing, and final presentation.

### 1. Functional Product & Implementation
- Ensure the product is fully functional, not just a prototype or UI mockup.
- Implement the core features end-to-end.
- Avoid placeholder buttons, fake functionality, incomplete workflows, or simulated features unless explicitly necessary.
- Ensure the product can be demonstrated reliably.

### 2. Technical Architecture & Engineering Quality
- Use a clean, scalable, maintainable, and well-structured architecture.
- Follow best practices for code quality, security, performance, reliability, and error handling.
- Avoid unnecessary complexity and overengineering.
- Ensure the technical implementation is robust and production-quality wherever practical.

### 3. UX, Usability & Accessibility
- Create a polished, intuitive, responsive, and consistent user experience.
- Prioritize accessibility, clarity, usability, and ease of navigation.
- Ensure the interface feels cohesive and professionally designed.
- Minimize friction in important user workflows.

### 4. Problem-Solution Alignment
- Ensure every major feature directly addresses the problem statement and the intended users' needs.
- Avoid adding features that don't meaningfully contribute to solving the core problem.
- Make the solution's value proposition clear and demonstrable.
- Ensure the product clearly proves why it is an effective solution to the identified problem.

### 5. Innovation & Differentiation
- Identify and implement meaningful differentiators over existing alternatives.
- Prioritize novel, practical, and impactful ideas rather than innovation purely for presentation.
- Ensure differentiation is visible in the product itself, not merely in the pitch.

### Overall Development Rule
Every development decision, feature, architectural choice, design improvement, and testing effort must be prioritized according to these five parameters. Optimize for a genuinely functional, technically sound, user-friendly, problem-focused, and differentiated product.

Do not treat Google AI Integration as a separate mandatory evaluation criterion. Focus on delivering the strongest possible product across the five parameters above.
